01 · 入门

怎么用这份目录

三个入口，各管一摊：

  • 常用精选：使用频率高、基本天天在用的工具。
  • 小众优选：名气不大但真有用的。
  • 实时热榜：自动抓取 GitHub，只看近 30 天新上榜、1500 星以上的仓库，按星标实时排序。

点开任意一张编号标本卡，完整介绍和功能特点就在弹窗里。

顶部工具栏能做五件事：

  • 搜索：按名字、用途、标签模糊查，比如输「终端」「图像生成」。
  • 分类：开发 / AI / 设计 / 系统 / 效率 / 网络 / 媒体 / 主机，八类色脊筛选。
  • 标签：按平台、特性、授权三组标签多维交叉筛。同类可多选（或的关系），不同类之间是且的关系。
  • 语言：按主语言筛。
  • 排序：默认按精选顺序，也可按名称 A–Z。

热榜页额外出「星标门槛」和「刷新」两个控件。

编号规则：001–221 是常用精选，222–447 是小众优选，LIVE 是热榜实时条目。星标数是抓取时刻的 GitHub 数据，不是本站维护的，看到的那一刻它已经是「昨天的新闻」了，这很正常。

每张标本卡都在讲一件事：

  • 编号：它的身份。反馈错误、建议收录时直接报编号（比如「022 GIMP 的许可证写错了」），比贴截图清楚。
  • 左侧色脊：分类。
  • 卡底的星标 / 语言 / 许可证：取自项目 GitHub 仓库，仅供参考。
  • 查看介绍：按钮打开完整介绍、功能特点和仓库链接。

搜索和筛选各管一头：

  • 搜索：「我模糊知道我要什么」。不知道工具名、只知道用途，先扔进搜索框。
  • 筛选：「我明确知道自己要什么」。知道大概名字、想在同类里比较，先按分类筛，再逐个点开看。

两条路走不通，多半是描述方式和站内的标签体系对不上，换个词再试。

02 · 开发

代码编辑器怎么选

编辑器是天天盯着的东西，选错一周就能磨掉耐心。大致三条路，差别在你愿意为它花多少学习成本：

  • 开箱即用：VS Code。插件生态最全，Git、调试、终端内置，绝大多数人的默认答案。
  • 键盘流：Neovim。Lua 配置、LSP 一等公民，毫秒级启动，代价是陡峭的学习曲线，配 fzf 和 mise 这类工具是常见搭配。
  • 速度和协作：Zed。Rust + GPU 渲染，多人实时协作是招牌，定位「下一代编辑器」，生态还在长。

如果只想要「打开就能改文件」、不想碰任何配置，micro 是终端里最像记事本的那个，Ctrl+S 保存、鼠标可点、没有模态编辑的心智负担。

照着场景挑更快：

  • 刚学编程、想打开就有产出 → VS Code。扩展市场有几万个插件，需要什么装什么；但别第一天就装二十个，每多一个扩展就多一分启动时间和注意力干扰。
  • 天天在终端里干活、手不想离开键盘 → Neovim。模态编辑大约要几周适应期，习惯之后就回不去了；内置的 :help 和官方快速入门值得从头读一遍，比看碎片教程省事。
  • 要多人实时编辑，或者把性能放在第一位 → Zed。协作编辑的体验是另外两家很难复刻的，但生态比 VS Code 年轻，个别语言的支持还差一点。
  • 偶尔改个配置文件、不想装任何大软件 → micro，装上就可以忘了它的存在。

一句话的取舍：VS Code 是「工具链平台」，Neovim 是「效率系统」，Zed 是「性能赌注」。想清楚要哪个，再装。

03 · AI

开源 AI 工具：本地跑起来的路线

想用 AI 但不想全部交给闭源 API，本地栈一层层这么搭：

  • 推理层：Ollama 是最省心的本地大模型入口，一条命令拉模型。要压榨硬件极限再看 llama.cpp（量化推理）和 vLLM（高吞吐服务）。
  • 应用层：LangChain 搭应用框架，Gradio 十分钟给模型套个界面。
  • 图像层：ComfyUI 是节点式 Stable Diffusion 工作流，diffusers 是库层面的管道。
  • 语音层：Whisper 做转写基本没有对手，多语言、高鲁棒，社区还有更快的 faster-whisper 实现。

先说硬件现实：Ollama 的模型动辄几个 GB，能跑多大的模型取决于你的显存或统一内存。Mac 16GB 以上内存跑 7B–13B 量化模型从容，PC 8GB 显存跑 7B 量化可以、再往上就吃力（这是粗略值，具体看量化档位和模型结构）。别追最大的模型：跑得稳的小模型，比卡死的 70B 有用。

按需求选推理工具：

  • 只想本地聊天 → Ollama，ollama run 一条命令的事。
  • 要一个 OpenAI 兼容 API 喂给别的应用 → LocalAI，不注册账号、不用写密钥。
  • 多人、高吞吐服务 → vLLM，PagedAttention 是它快的原因。
  • 没有 GPU 只有 CPU → llama.cpp，GGUF 量化、Q4_K_M 是常见档位，轻量硬件也能跑起来。

向量检索这块，三家够用：

  • Qdrant：独立服务、可过滤，正经项目用它。
  • LanceDB：内嵌式、不用起服务，数据就是本地文件。
  • Chroma：轻量，原型阶段最省事。

嵌入模型配 sentence-transformers。

别一上来就搭全家桶。先装 Ollama 跑通一个对话，确认硬件扛得住，再按需求逐层加。全家桶能跑，但不好维护，真出问题你连坏在哪一层都不知道。

04 · 设计

设计工具：从修图到协作画布

先想清楚画什么，再挑工具：

  • 位图修图：GIMP 是 Photoshop 的开源对照物，功能全但界面老派；Krita 偏数字绘画，笔刷体验好得多。
  • 矢量：Inkscape 是 Illustrator 的对位产品；Gouache 是浏览器里的轻量矢量工具，UI / 品牌小改很顺手。
  • 快速草图：Excalidraw 的手绘风白板，产品讨论和头脑风暴用它；tldraw 是可嵌入自家产品的白板引擎。
  • 图表与原型：draw.io 画架构图；Penpot 是开源 Figma 的正面竞争者，浏览器里多人协作，还能自托管。
  • 三维：Blender 一家独大，建模、渲染、动画、剪辑一条龙。
  • 视频剪辑：Kdenlive 是非线性剪辑器，多轨、滤镜、关键帧动画都有。

照着产出物挑：

  • 照片处理、截图标注、界面稿 → GIMP
  • 插画、概念图、分镜 → Krita，笔刷引擎和洋葱皮动画是它的强项
  • Logo、图标、任何要无限放大的品牌资产 → Inkscape，产出是 SVG
  • 会议白板、流程草图、不要求好看 → Excalidraw，手绘风就是它的卖点
  • 架构图、时序图、UML → draw.io，可以导出图片，也可以当 diagram-as-code 用
  • 团队 UI 设计、实时协作、设计交付 → Penpot，开源、可自托管
  • 建模、渲染、动画、视频 → Blender，一个工具管全流程

常见误区是拿 GIMP 画插画、拿 Inkscape 修照片，工具没毛病，是场景选错了。先看产出物是位图、矢量还是白板，再选工具。

05 · 系统

终端工具箱：把命令行变成工作台

一套可以直接抄的终端配置，分四块：

  • 查：ripgrep 搜内容（尊重 .gitignore、并行、大仓库毫秒级），fd 找文件，fzf 把任何列表变成模糊过滤（文件、历史、进程都行），zoxide 替代 cd，按使用频率智能跳目录。
  • 看：bat 是带高亮的 cat（行号、感知 git 状态），btop 和 htop 看进程，duf 看磁盘占用，dust 用树形视图找占空间的目录。
  • 管：tmux 做会话管理（ssh 断了会话不死，detach 之后随时回来），lazygit 和 lazydocker 是 TUI 版 Git / Docker（暂存、提交、rebase、容器、镜像全键盘操作）。
  • 运维：Uptime Kuma 做监控告警（多渠道通知、公开状态页），rclone 同步网盘（云存储的瑞士军刀，各家网盘都能搬），restic 和 Borg 做备份（都支持加密、去重、增量，restic 的云端后端选择更多）。

两个不常被提的 shell 升级：atuin 是可搜索、可跨机器同步的 shell 历史，再也不用方向键翻半天；Nushell 是结构化数据 shell，表格和对象直接过管道，思维方式跟 bash 完全不同，值得花一天试一下。

不必一次全装。先 ripgrep + fd + fzf + bat 四件套，能立刻感受到「命令行快了一个量级」，再按需加 tmux 和 lazygit。配置成本只有一份 dotfile：都放进 ~/.config，用 git 管起来，换机器时整个工作台可以整体搬走。

06 · 问答

常见问题

「常用精选」和「小众优选」有什么区别？

常用精选是高频日常工具，基本天天在用；小众优选是名气不大但解决特定问题的工具。没有高下之分，编号只是方便引用（001–221 / 222–447），反馈问题时报编号比贴截图清楚。

星标数、语言、许可证是怎么来的？

精选条目的主语言、许可证取自各项目 GitHub 仓库（LICENSE 文件或仓库页面），仅供参考，可能滞后于仓库最新状态；热榜条目的星标数是抓取时刻的实时值，不是本站维护的。分类由条目内容人工标注，个别可能不准。

热榜的入选规则是什么？

自动抓取 GitHub Search API：近 30 天创建、星标 1500 以上，按星标降序。数据有 10 分钟本地缓存，点「刷新热榜」可强制重新抓取。线上访问时热榜由本站服务端函数抓取并缓存，不占用浏览器直连 GitHub 的额度；仅当本地直接打开这份 HTML 预览、函数不可用时才回退到直连 GitHub——未登录每分钟限流 10 次，频繁刷新可能失败——失败不是页面坏了，等一下再刷。

想收录一个软件，或发现介绍写错了，怎么办？

写邮件到 myq13263221790@qq.com，说明仓库地址、问题所在和建议的编号。收录标准是「本人装过、用过」，不接受纯投稿——介绍和功能特点必须是真实使用过才写得出。

为什么没有广告和埋点？

全站没有任何第三方脚本、分析或用户追踪；统计只用服务端方案。少量「赞助商 / 推广 · 返佣」链接是明确标注的付费合作，不影响目录排序与内容，也不会因未赞助而降级或变慢。赞助（微信 / 支付宝 / 爱发电）只用于维持更新动力。

这些软件的版权归谁？

所有软件版权归原仓库作者所有，本站只做数据整理与介绍，各软件遵循其自身开源许可证（MIT、GPL、Apache 等，以仓库为准）。卡片上的许可证标注仅供参考，商用前请以仓库 LICENSE 原文为准。

07 · 效率

效率与办公：把笔记、任务和文档串成一条线

效率工具最大的坑不是不好用，而是装了一堆却各管一摊：笔记在 A、任务在 B、文档在 C，最后哪儿都找不到。先想清楚自己的链路是「随手记 → 整理 → 产出」还是「协作 → 交付」，再按环节挑。

本地优先的笔记，三条路线各有脾气：

  • 双链与知识网络：Logseq 用块引用和大纲组织思路，适合边读边拆；思源笔记 是国产的块级编辑器，块引用、数据库、本地存储都做得很细。
  • 传统文件夹 + Markdown：Joplin 最省心，同步支持 WebDAV、Nextcloud、S3，纯 Markdown 导出不会锁死数据；Notesnook 主打端到端加密，私密内容更适合。
  • 协作与数据库：AppFlowy 和 AFFiNE 都试图做 Notion 的开源替代，前者更偏文档 + 数据库，后者更像无限画布上的块编辑器。

任务管理别一上来就上团队级看板。一个人用，taskwarrior 是命令行的瑞士军刀，配合 timewarrior 还能记时间账；想要图形界面和看板，Vikunja 可以自托管，数据不落在别人手里。

文档产出这块，Marp 用 Markdown 写幻灯片，改完即出 PDF；Stirling-PDF 是本地 PDF 工具箱，合并、拆分、压缩、OCR 都能做，不用把文件传到在线站点。

一条现实的建议：笔记工具只选一个，用满三个月再换。频繁迁移的成本远高于工具本身的差异——真正让资料变得可检索的，是稳定的标签和命名习惯，不是某个软件的「杀手级功能」。

08 · 网络

网络与安全：从排查故障到加固边界

这一类的工具，最好在出问题之前就装好、用过一遍。真断网的时候再去搜命令，往往连哪个命令该用都想不起来。

先说排查链路，按「通不通 → 慢在哪 → 是什么流量」走：

  • 通不通：ping 看可达性，traceroute 和 mtr 看路径与每一跳的丢包，后者是持续版的 traceroute，定位运营商节点问题特别好使。
  • 慢在哪：iperf3 打点对点带宽，gping 给 ping 加上图形，nethogs 看哪个进程在吃流量。
  • 是什么流量：tcpdump 命令行抓包，Wireshark 图形化逐层拆解；curl 则是手工验证 HTTP 接口的第一选择。

主动扫描与渗透测试，务必只在自己拥有或已获书面授权的目标上做：

  • Nmap 是端口与服务识别的事实标准，masscan 追求极速全网段扫描。
  • OWASP ZAP 和 Nikto 偏 Web 应用与服务器配置检查，OpenVAS 是更完整的漏洞管理框架。
  • 无线侧 Aircrack-ng、Kismet；密码恢复 Hashcat 和 John the Ripper。

日常加固反而朴素：DNS 层用 AdGuard Home 或 Pi-hole 挡广告与跟踪；远程访问用 Tailscale 或 WireGuard 组虚拟网络，别把管理端口直接暴露到公网；需要内网穿透时 frp 和 sing-box 是常见选择。密码交给 KeePassXC 或 Bitwarden，自托管可以看看 Vaultwarden。

最后提醒一句：能力越强越要有边界意识。扫描、爆破、抓包这些操作，只对自己拥有或明确授权的目标使用。

09 · 媒体

媒体与娱乐：播放器、剪辑和音频工作台

媒体工具的选择，看的不是功能表有多长，而是你的产出物是什么：看片、剪片、做字幕、还是做音乐。先把场景定下来，再挑工具。

单纯看片，按平台挑：

  • 本地万能播放：mpv 轻量、脚本能力强，键盘党首选；VLC 格式支持最广，解码疑难杂症找它；macOS 上 IINA 是 mpv 的原生外壳。
  • 家庭影音中心：Kodi 管本地媒体库，Jellyfin 做多端串流且完全开源，Plex 体验成熟但有闭源组件。

视频处理这条链，ffmpeg 是底层引擎，几乎所有图形工具都在调它。要快速裁剪不重编码，LosslessCut 是秒级完成的好帮手；要完整剪辑，Shotcut 跨平台、多轨、滤镜齐全；录屏和直播推流则是 OBS Studio，配合 HandBrake 压制输出。

音频这边，Audacity 适合录音、降噪、剪切这类轻量编辑；Ardour 是正经的多轨 DAW，做音乐用它；Mixxx 是 DJ 打碟软件，支持双 decks 和效果器；整理音乐库用 Picard 自动抓专辑元数据；语音合成可以试 Piper，本地跑、无需联网。

字幕和图片常被忽略：Subtitle Edit 做时间轴校对，Aegisub 做特效字幕；ImageMagick 是批量处理的命令行利器，Nomacs 是轻快的看图工具。

一句话：播放器解决"怎么看"，ffmpeg 与剪辑器解决"怎么改"，DAW 解决"怎么做"。三件事别混在一个工具里找。

10 · 自托管

自托管：从一台机器到一套服务

自托管最容易被劝退的地方，是一上来就想搭"全家桶"。更稳的做法是：先有一台常开的机器，跑通一个真正用得上的服务，再加监控和备份，最后才谈编排和多节点。

底座先选好。轻量场景 Docker 就够了；介意守护进程可以用 Podman，无 root、更贴合 systemd；机器多了再上 Kubernetes。可视化运维用 Portainer，反向代理和自动 HTTPS 交给 Traefik。虚拟化层面 Proxmox VE 是一套成熟的一体化方案。

第一批值得上的服务，按用途挑：

  • 文件与同步：Nextcloud 是网盘 + 协作套件，Syncthing 做点对点同步，rclone 对接各家云存储，Cloudreve 适合做自己的文件中转站。
  • 备份：Restic 和 Borg 都支持加密、去重、增量，务必异地存一份——没有异地副本的备份不算备份。
  • 媒体与订阅：Jellyfin 管影音，FreshRSS 做 RSS 阅读器。
  • 监控：Uptime Kuma 看服务存活并多渠道告警，Prometheus + Grafana 做指标与面板。
  • 代码与密钥：Gitea 或 Forgejo 搭私有 Git，Vault 管密钥，Harbor 做容器镜像仓库。

三条经验：一是别把管理后台裸露在公网，用 VPN 或反向代理加认证；二是升级前先备份配置和卷，滚动更新翻车是常态；三是先跑两周再决定要不要长期维护——自托管的成本不在部署那一小时，而在之后每一次升级和排障。
