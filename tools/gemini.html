Gemini

★ 0Python闭源对照更新 2026-11-28

Google 的多模态 LLM 系列。

介绍

Gemini 是 Google 的模型系列核心，文本、图像、音频、视频都能理解和生成，推理、多模态、代码任务上成绩靠前，上下文也长。通过 API 和 Gemini App 提供服务。要用 Google 的多模态能力，找它就对了。

功能特点

  • 文本、图像、音频、视频全模态
  • 推理和代码是强项
  • 上下文窗口长
  • API 加 Gemini App
  • Google AI 战略核心
  • 商业平台，多模态领先

下载与安装

git clone https://github.com/google-gemini/gemini-api.git
