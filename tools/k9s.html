k9s

★ 0GoApache-2.0更新 2026-11-28

Kubernetes 的终端界面，一个窗口看遍集群。

介绍

kubectl 的输出读起来累，k9s 把集群变成可导航的终端界面：上下键切资源，回车看详情，热键做 scale、日志、shell、port-forward。它比Lens轻，SSH 隧道一连就能管远程集群，日常排查 Pod、看事件、翻日志效率明显高于一行行敲 kubectl。资源视图可按 namespace 过滤，也能自定义快捷命令。

功能特点

  • 终端里的资源浏览器，键盘导航为主
  • 日志、事件、exec、port-forward 热键直达
  • 支持 scale / rollout / 删除等常用操作
  • 多集群多上下文切换方便
  • 可自定义插件与快捷键
  • 跨平台单二进制，SSH 隧道即可用

下载与安装

git clone https://github.com/derailed/k9s.git
