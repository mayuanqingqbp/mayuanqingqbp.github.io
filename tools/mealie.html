Mealie

★ 0PythonAGPL-3.0更新 2026-11-28

自托管食谱管理：抓网页食谱，购物清单和餐食计划

介绍

Mealie 解决的痛点很生活化：网页食谱格式乱、广告多，它支持粘贴 URL 自动抓取成结构化食谱，也能手动录入，然后按食材生成购物清单、做一周餐食计划。界面清爽，移动端友好，多用户共享一个实例，数据在自己数据库里可导出。自托管家庭工具里它属于「装完真的会天天用」的那类。

功能特点

  • 粘贴链接自动抓取网页食谱
  • 食材、步骤、营养、图片结构化管理
  • 购物清单与餐食计划
  • 多用户与家庭共享，支持移动端
  • 支持标签、收藏、全文搜索
  • 数据可导出，备份简单

下载与安装

git clone https://github.com/mealie-recipes/mealie.git
