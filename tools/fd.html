fd

★ 45.1kRustMIT版本 v10.5.1更新 2026-11-25

简单、快速、友好的 find 替代品。

介绍

fd 是一个简单、快速且用户友好的 find 命令替代品。它用 Rust 编写，直接调用操作系统的原生搜索 API（如 Linux 的 readdir），比 find 快得多，语法也直观得多——不用写复杂的 -type -name 表达式。它默认尊重 .gitignore、跳过隐藏文件，输出清晰友好，快速找文件，用它比 find 省事。

功能特点

  • 调用操作系统原生搜索 API，比 find 快得多
  • 语法简单友好，不用复杂表达式
  • 默认尊重 .gitignore、跳过隐藏文件
  • 清晰、彩色的输出
  • Rust 编写、单二进制、跨平台
  • 支持并行搜索、正则、文件类型过滤
