LocalAI

★ 50.4kGoApache-2.0版本 v4.12.1更新 2026-11-25

本地运行 AI 模型的运行时，兼容 OpenAI API，开箱即用。

介绍

LocalAI 是本地运行 AI 模型的开源运行时，提供与 OpenAI API 兼容的接口。你可以在本地跑 LLM、图像生成、语音合成等多种模型，并把它们直接接到现有的 OpenAI 集成里，无需改代码。支持多种推理后端，Docker 一键部署。

功能特点

  • OpenAI 兼容 API，直接替换无需改代码
  • 支持 LLM、图像生成、TTS 等多模态模型
  • 后端抽象：llama.cpp、ONNX 等多种推理引擎
  • GPU 加速与多模型部署
  • Docker 部署，开箱即用
  • 完全本地运行，隐私安全
