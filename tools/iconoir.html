Iconoir

★ 4.6kTypeScriptMIT更新 2026-11-28

开源线性图标库，2500 多枚图标，风格统一。

介绍

Iconoir 是开源线性图标库，2500 多枚图标风格高度统一，UI 设计里常见的基本都覆盖。全量 SVG 格式，主题、颜色、描边粗细都能改，React、Vue、图标字体等集成方式也备着。设计师找图标，它的性价比很高。

功能特点

  • 2500 多枚线性图标，风格、粗细、圆角统一
  • 全是 SVG，颜色、描边、主题按需改
  • React、Vue、Svelte 组件库可直接引入
  • 图标字体、sprite 等集成方式都有
  • 分类清楚，好搜，UI 场景覆盖广
  • 开源免费，可商用

下载与安装

git clone https://github.com/iconoir-icons/iconoir.git
