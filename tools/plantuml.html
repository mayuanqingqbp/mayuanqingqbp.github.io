PlantUML

★ 0JavaMIT / GPL / LGPL更新 2026-11-25

老牌文本绘图工具，UML 全家桶和架构图都能画。

介绍

PlantUML 比 Mermaid 更早，语法更贴近 UML 规范，类图、用例图、组件图、部署图这类正式图表更完整。它是 Java 写的，命令行、IDEA/VS Code 插件、在线渲染服务器各种用法都有，输出 SVG/PNG/PDF/HTML。我的经验是：轻量随手画用 Mermaid，需要严格 UML 语义或者画大型系统结构时用 PlantUML，它对布局和关联线的处理更稳。

功能特点

  • UML 支持最完整：类、序列、用例、组件、部署、状态
  • 也支持架构图、思维导图、甘特、网络拓扑
  • 命令行、IDE 插件、在线渲染服务多种用法
  • 输出 PNG/SVG/PDF/TeX，可接 LaTeX 排版
  • 皮肤参数可调，能统一整套图的观感
  • 多许可并行发布，按版本选合适的即可

下载与安装

git clone https://github.com/plantuml/plantuml.git
