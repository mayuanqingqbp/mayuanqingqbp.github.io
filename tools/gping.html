gping

★ 12.7kGoMIT更新 2026-11-28

把 ping 的延迟实时画成图。

介绍

gping 给 ping 加上了图表。延迟不再是一行行数字，而是实时画成曲线，波动一眼看见。Go 编写，跨平台，单二进制。想查网络延迟稳不稳，跑一下它就知道了。

功能特点

  • 延迟实时画成曲线
  • 波动一眼能看出来
  • Go 编写，跨平台，单二进制
  • 可以同时 ping 多个目标
  • 查网络延迟，跑一条命令就够
  • 图表直接画在终端里

下载与安装

git clone https://github.com/orf/gping.git
