Nushell

★ 41.0kRustMIT版本 0.116.1更新 2026-11-25

以结构化数据为核心的现代 shell，管道里直接处理表格与对象。

介绍

Nushell 是一个现代 shell，它的核心理念是让数据“结构化”。在它的管道里，文件、HTTP 响应、配置文件都变成可以直接过滤、排序、聚合的表格和对象，而不是纯文本。可以把它理解成“Unix 世界的 PowerShell”，用命令处理数据就像用 SQL 处理数据库。

功能特点

  • 结构化数据：命令输出是表格 / 对象，不是裸文本
  • 管道链式操作：ls | where size > 10mb | sort-by modified，一目了然
  • 内置命令：HTTP 请求、JSON / YAML / TOML 解析、数据库查询
  • 丰富的自动补全与帮助文档
  • 跨平台、单二进制，安装即用
  • 脚本可写，适合自动化与数据管道
