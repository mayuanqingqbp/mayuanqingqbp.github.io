MySQL

★ 12.5kC++GPL-2.0更新 2026-11-25

最流行的开源关系数据库，Web 应用的后端基石。

介绍

MySQL 是全球部署量最大的开源关系数据库，由瑞典 MySQL AB 创建，后被 Oracle 收购。它以性能、易用性和成熟的生态著称，是 LAMP 架构的核心，支撑着海量 Web 应用。InnoDB 引擎提供事务与行级锁，配合主从复制与分库分表，能扩展到非常大的规模。

功能特点

  • InnoDB 引擎：事务、行级锁、崩溃恢复
  • 主从复制与高可用方案成熟
  • 丰富的存储引擎可选
  • 庞大的生态与工具链，文档齐全
  • 性能优化手段多：索引、查询缓存、分区
  • 开源（GPL-2.0），跨平台，社区极其活跃

下载与安装

git clone https://github.com/mysql/mysql-server.git
