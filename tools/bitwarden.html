Bitwarden

★ 20.7kTypeScriptGPL-3.0更新 2026-11-28

开源密码管理器，服务器可自托管，全平台同步。

介绍

Bitwarden 是开源的密码管理方案，客户端全平台覆盖，服务器可以自己托管。密码、SSH 密钥、支付卡、安全笔记集中管，主密码加端到端加密保护，不必绑在任何一家云厂商上。

功能特点

  • 服务器可自托管，密码库数据完全在自己手里
  • 客户端加密后才上传，服务器只见密文
  • 桌面、浏览器、手机、命令行客户端都有，还提供 API
  • 强密码生成、表单自动填充，SSH 密钥和支付卡也能管
  • 团队共享集合、权限控制，团队密钥管理够用
  • 开源免费，社区维护的 Vaultwarden 更轻量好部署

下载与安装

git clone https://github.com/bitwarden/server.git
