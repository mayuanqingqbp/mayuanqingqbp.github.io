Snort

★ 3.5kCPPGPL-2.0更新 2026-11-25

经典网络入侵检测系统

介绍

Snort 是老牌开源网络入侵检测/防御系统，用规则匹配流量中的恶意特征。它是 IDS 领域的奠基者之一，规则生态庞大，至今仍被广泛部署在各类网络环境中。

功能特点

  • 基于规则的流量特征检测
  • 支持入侵检测与内联防御模式
  • 庞大的社区与企业规则集
  • 协议分析与内容匹配
  • 轻量、稳定，适合各类网络

下载与安装

git clone https://github.com/snort3/snort3.git
