scc

★ 8.9kCGPL-3.0更新 2026-11-25

极速代码行数统计工具，比 tokei 更快。

介绍

scc（Sloc C Code）是一款用 C 编写的很快的代码行数统计工具，比 tokei 更快，能统计代码、注释、空行的占比。scc 支持数百种语言，可输出表格、JSON，适合大型项目的代码规模分析。它的性能优势让它成为代码统计的新选择。

功能特点

  • 极速统计：比 tokei 更快
  • 代码/注释/空行占比分析
  • 支持数百种语言
  • 表格、JSON 输出
  • 大型项目代码规模分析
  • 开源（GPL-3.0），跨平台，性能优秀

下载与安装

git clone https://github.com/boyter/scc.git
