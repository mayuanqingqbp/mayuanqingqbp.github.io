Giskard

★ 6.0kPythonApache-2.0更新 2026-11-25

ML 与 LLM 模型安全测试框架，找漏洞。

介绍

Giskard 是一款 ML 与 LLM 模型的安全测试框架，它自动找模型的漏洞（偏见、鲁棒性、数据泄露、提示注入等）。Giskard 像“模型的渗透测试”，帮团队发现模型的安全与公平性问题。它是模型安全领域的领先开源工具。

功能特点

  • 模型安全与公平性测试
  • 自动发现偏见、鲁棒性问题
  • 提示注入检测
  • 数据泄露检测
  • 测试报告与修复建议
  • 开源（Apache-2.0），跨平台，模型安全

下载与安装

git clone https://github.com/Giskard-AI/giskard.git
