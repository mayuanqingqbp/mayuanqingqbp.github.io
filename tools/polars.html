polars

介绍

polars 是一个很快的数据框库。它支持惰性求值与并行处理，在大数据量下比 pandas 快得多。它用 Rust 编写、提供 Python API，高性能数据处理，它够快。

功能特点

  • 极速，大数据量下比 pandas 快得多
  • 惰性求值、并行处理
  • Rust 编写、提供 Python API
  • 适合高性能数据处理
  • 跨平台
  • API 直观易用

下载与安装

git clone https://github.com/pola-rs/polars.git
