glow

★ 28.1kGoMIT版本 v3.0.0更新 2026-11-25

终端里漂亮地渲染 Markdown，语法高亮、响应式布局。

介绍

glow 是面向终端的 Markdown 渲染器。它读取一个 Markdown 文件，直接在终端里渲染成排版干净、易读的页面，支持代码语法高亮、表格、引用等。你可以直接指向文件，也可以把内容从管道喂给它，是快速预览 README、文档而不用离开终端的理想伴侣。

功能特点

  • 终端内渲染 Markdown，排版干净易读
  • 代码语法高亮、表格、引用、图片
  • 可直接指向文件，也可从 stdin 管道读取
  • 主题支持，可切换配色方案
  • 跨平台、单 Go 二进制
  • 适合在终端里快速预览 README 与文档
