tig

★ 0CGPL-2.0更新 2026-11-25

终端里的 git 仓库浏览器。

介绍

tig 是一款终端里的 git 仓库浏览器，用 C 编写，极轻量。它提供可视化的提交历史、分支、差异浏览，支持交互式操作（查看、cherry-pick、revert）。tig 是命令行 git 的有力补充，让仓库历史在终端里清晰可读，适合喜欢终端的用户。

功能特点

  • 终端里可视化 git 历史
  • 分支、提交、差异浏览
  • 交互式操作：cherry-pick、revert
  • 用 C 编写，极轻量
  • 与 git 命令配合使用
  • 开源（GPL-2.0），跨平台，经典工具
