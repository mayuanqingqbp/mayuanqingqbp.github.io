Qdrant

高性能向量数据库，语义搜索与 RAG 基础设施。

介绍

Qdrant 是一个高性能的向量数据库，专为语义搜索和机器学习工作负载而优化。它把向量与关联的载荷（payload）一起存储，提供强大的过滤能力，支持多种索引与量化，是 RAG（检索增强生成）和语义搜索的核心组件。它提供 REST / gRPC API，Docker 一键即可部署。

功能特点

  • 高性能向量存储与检索，语义搜索低延迟
  • 丰富过滤：标量属性与向量结合，精准检索
  • 量化与索引，省内存、提速度
  • REST / gRPC API，多语言客户端 SDK
  • 支持分布式部署与水平扩展
  • Docker 一键部署，自带可观测性
