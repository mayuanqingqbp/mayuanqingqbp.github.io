Homebrew

macOS（也支持 Linux）上的软件包管理器，brew 一条命令装软件。

介绍

Homebrew 是 macOS（也支持 Linux）上的免费开源包管理器。一条 brew install 命令就能安装数千款命令行工具和应用程序，它管理依赖、自动升级，是 macOS 开发体验的标配部分。社区维护的 tap 机制让软件包生态持续扩展。

功能特点

  • 一条命令安装：brew install <软件>
  • 海量软件包（formulae）与应用（casks）
  • 依赖管理、自动升级
  • tap 机制：社区维护的扩展仓库
  • 跨平台（macOS、Linux）
  • 完全开源，生态成熟
