Poetry

Python 包与依赖管理器，poetry.lock 保证可复现。

介绍

Poetry 是一款现代的 Python 包与依赖管理工具，它把项目管理、虚拟环境、依赖锁定整合在一起。Poetry 用 pyproject.toml 声明依赖，生成 poetry.lock 锁定精确版本，保证构建可复现。它让 Python 项目的依赖管理从“手动折腾”变成“一条命令搞定”。

功能特点

  • pyproject.toml 声明依赖，标准格式
  • poetry.lock 锁定精确版本，可复现
  • 自动管理虚拟环境
  • 依赖解析智能，冲突自动处理
  • 打包与发布到 PyPI 一条命令
  • 开源（MIT），跨平台，Python 社区主流
