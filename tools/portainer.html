Portainer

★ 38.8kGoApache-2.0更新 2026-11-28

Docker 与 Kubernetes 的图形化管理面板。

介绍

Portainer 给 Docker、Swarm、Kubernetes 套了个图形界面。镜像管理、容器启停、日志查看、网络和卷管理、用户权限，这些本来要敲命令的事，现在点鼠标就行。自建服务器上管容器，拿它当可视化入口，上手门槛低不少。

功能特点

  • 容器、镜像、网络、数据卷都图形化管
  • Swarm 与 Kubernetes 集群也支持
  • 日志、启停、资源监控，界面里看
  • 有用户与权限控制，团队能一起用
  • 模板市场，常见自托管应用一键部署
  • 社区版开源免费，本身也用 Docker 部署

下载与安装

git clone https://github.com/portainer/portainer.git
