SuiteCRM

★ 5.9kPHPAGPL-3.0更新 2026-11-25

开源 CRM 客户关系管理

介绍

SuiteCRM 是 SugarCRM 社区版的开源分支，是功能完整的企业级 CRM。它覆盖销售自动化、客户服务和营销，适合需要深度定制又不愿付商业授权的组织。

功能特点

  • 线索、机会、客户与合同管理
  • 销售流程与报表分析
  • 邮件集成与市场营销模块
  • 高度可定制的模块与工作流
  • PHP 开源，可自托管

下载与安装

git clone https://github.com/SuiteCRM/SuiteCRM.git
