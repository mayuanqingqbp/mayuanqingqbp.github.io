Nginx Proxy Manager

★ 0JavaScriptMIT更新 2026-11-28

带 Web 界面的 Nginx 反代管理器，配域名证书点几下。

介绍

自建服务最烦的是重复配 Nginx：加个域名、签发证书、配转发、跳转 HTTPS。Nginx Proxy Manager 用 Docker 起一个容器，之后这些都在网页上点：填域名和上游端口，Let's Encrypt 自动签发续期，重定向、访问控制、代理头都能配。NAS 和家用服务器上几乎成了标配。进阶需求（自定义 location、限流）可以挂额外配置文件。

功能特点

  • 图形界面配置反向代理与转发规则
  • Let's Encrypt 自动签发与续期，支持 DNS 验证
  • HTTP 跳转、SSL 参数、代理头可调
  • 支持访问授权、自定义 404、重定向
  • Docker 一键部署，数据持久化简单
  • 家用 NAS 上跑没有负担

下载与安装

git clone https://github.com/NginxProxyManager/nginx-proxy-manager.git
