Jira

★ 649Java闭源对照更新 2026-11-25

Atlassian 项目管理与敏捷跟踪工具。

介绍

Jira 是 Atlassian 的项目管理与问题跟踪工具，支持敏捷（Scrum、看板）、自定义工作流、报表。Jira 是软件开发团队的项目管理标准，功能强大但配置复杂。它是企业敏捷开发的主流工具。

功能特点

  • 敏捷与看板管理
  • 自定义工作流
  • 报表与仪表盘
  • 与 Confluence 集成
  • 企业级，功能强大
  • 商业软件（Atlassian），跨平台，项目管理标准

下载与安装

git clone https://github.com/atlassian/jira.git
