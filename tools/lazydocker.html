lazydocker

终端里的 Docker 图形界面，管理容器、镜像、日志不离开终端。

介绍

lazydocker 是一个跑在终端里的 Docker TUI（文本图形界面）。它把复杂的 Docker 命令行操作变成一套清晰的交互界面——查看容器状态、启停、看日志、进容器执行命令、管理镜像与卷，全都能一键完成。它是 lazygit 的姊妹项目，重度用 Docker 的人，基本都装一个。

功能特点

  • Docker 全套操作：容器启停、重启、删除、进容器执行命令
  • 交互式查看日志，实时过滤与搜索
  • 管理镜像、卷、网络、compose
  • 容器资源占用一目了然，stats 视图
  • 单二进制、零依赖，任何终端都能跑
  • lazygit 姊妹项目，同作者、同风格
