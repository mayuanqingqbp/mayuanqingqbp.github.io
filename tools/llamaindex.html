LlamaIndex

★ 0PythonMIT更新 2026-11-28

把自有文档接给大模型的框架：索引、检索、RAG。

介绍

LlamaIndex 专管「让模型读你的资料」这一环：加载各种来源（PDF、Notion、数据库、网页），切块、建索引（向量、关键词、知识图谱），检索时做重排与组合，再交给模型回答。它比从零拼 embedding + 向量库省事，抽象层次多，可按需要只用其中一部分。和 LlamaIndex 相对的是 LangChain：后者偏流程编排，前者偏数据接入与检索质量。

功能特点

  • 数百种数据读取器与文件格式支持
  • 向量 / 关键词 / 混合检索与重排
  • 索引持久化，可换多种向量数据库
  • 查询引擎、Agent、路由可组合
  • 知识图谱索引与结构化抽取
  • 与主流模型和框架互通

下载与安装

git clone https://github.com/run-llama/llama_index.git
