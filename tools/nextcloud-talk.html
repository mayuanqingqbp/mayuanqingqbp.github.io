Nextcloud Talk

Nextcloud 视频会议

介绍

Nextcloud Talk 是 Nextcloud 生态里的音视频通话与聊天组件，把会议能力集成进你自己的云盘。它自托管、注重隐私，适合想在自有平台上开会而无需依赖第三方服务的团队。

功能特点

  • 音视频会议与屏幕共享
  • 与 Nextcloud 文件、日历深度集成
  • 端到端加密通话（实验性）
  • 可自托管，数据不出内网
  • 有移动端与浏览器客户端
