Open WebUI

★ 0PythonOpen WebUI License更新 2026-11-25

自建的大模型对话界面，接 Ollama 与各家 API。

介绍

Open WebUI 是自托管的 ChatGPT 风格前端：本地 Ollama 模型、OpenAI 兼容 API、各类网关都能接，界面里有知识库（RAG）、工具与函数、多用户与权限、提示词商店、语音与图像。它是这两年自建 AI 环境里最常被装上的一个，功能密度高但部署只是一条 Docker 命令。企业场景注意它的许可带商用限制条款，自使用前要看一遍 LICENSE。

功能特点

  • 接 Ollama、OpenAI 兼容接口与多家网关
  • 内置 RAG 知识库与文档检索
  • 工具 / 函数 / 工作流可自定义扩展
  • 多用户、权限组与审计
  • 提示词与模型预设可分享
  • 离线自托管，数据不出内网

下载与安装

git clone https://github.com/open-webui/open-webui.git
