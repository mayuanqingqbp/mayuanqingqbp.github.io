asdf

★ 25.6kRubyMIT更新 2026-11-28

一个工具管所有运行时的版本。

介绍

asdf 是通用运行时版本管理器：Python、Node、Ruby、JVM 等几十种运行时，用同一个工具管版本。按项目、按目录设置，.tool-versions 往项目里一放就完事。过去每个语言装一个版本管理器的混乱，一个 asdf 收掉了。

功能特点

  • 多种运行时的版本统一管
  • 按项目或目录设版本
  • 靠插件支持几十种语言
  • .tool-versions 声明项目版本
  • 一个工具替掉一堆工具
  • 开源（MIT），跨平台

下载与安装

git clone https://github.com/asdf-vm/asdf.git
