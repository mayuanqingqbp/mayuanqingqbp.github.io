dig

★ 791CBSD更新 2026-11-25

DNS 查询工具，灵活强大。

介绍

dig 是 DNS 查询工具，支持 A、AAAA、MX、TXT 等记录查询，显示完整的 DNS 响应。dig 是 DNS 调试与查询的标准工具，比 nslookup 更灵活。它是 DNS 查询的专业工具。

功能特点

  • DNS 查询
  • A、AAAA、MX、TXT 等
  • 完整响应显示
  • DNS 调试
  • 灵活强大
  • 开源（BSD），跨平台，DNS 查询

下载与安装

git clone https://github.com/ISC-projects/bind9.git
