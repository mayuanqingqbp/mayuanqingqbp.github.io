pnpm

★ 37.1kTypeScriptMIT版本 v12.18.0更新 2026-11-25

快速省磁盘的 JS 包管理器，硬链接 + 内容寻址存储。

介绍

pnpm 是一个快速且节省磁盘空间的 JavaScript 包管理器。它采用全局内容寻址存储，所有包以硬链接方式共享，装多个项目也不会重复占盘，安装速度和成功率都很高。它原生支持 monorepo 工作区，是大型前端项目的默认选择之一。

功能特点

  • 内容寻址全局存储 + 硬链接，包不重复占用磁盘
  • 安装速度快，支持增量安装与并行下载
  • 严格的 node_modules 结构，避免幽灵依赖
  • 原生 monorepo 支持（workspaces），跨项目依赖链接
  • lockfile 与 npm 兼容，迁移成本低
  • 内置脚本运行与依赖管理
