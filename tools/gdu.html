Gdu

★ 6.2kGoMIT更新 2026-11-25

快速磁盘使用分析工具

介绍

Gdu 是一款用 Go 写的快速磁盘使用分析工具，是 ncdu 的现代替代品。它并行扫描磁盘，界面交互流畅，能迅速找出占空间最大的目录和文件。

功能特点

  • 并行扫描，速度远快于传统工具
  • 交互式查看目录占用
  • 支持按大小排序与筛选
  • 可删除文件并实时更新
  • 终端 TUI，跨平台单文件

下载与安装

git clone https://github.com/dundee/gdu.git
