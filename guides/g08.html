网络与安全：从排查故障到加固边界

这一类的工具，最好在出问题之前就装好、用过一遍。真断网的时候再去搜命令，往往连哪个命令该用都想不起来。

先说排查链路，按「通不通 → 慢在哪 → 是什么流量」走：

  • 通不通：ping 看可达性，traceroute 和 mtr 看路径与每一跳的丢包，后者是持续版的 traceroute，定位运营商节点问题特别好使。
  • 慢在哪：iperf3 打点对点带宽，gping 给 ping 加上图形，nethogs 看哪个进程在吃流量。
  • 是什么流量：tcpdump 命令行抓包，Wireshark 图形化逐层拆解；curl 则是手工验证 HTTP 接口的第一选择。

主动扫描与渗透测试，务必只在自己拥有或已获书面授权的目标上做：

  • Nmap 是端口与服务识别的事实标准，masscan 追求极速全网段扫描。
  • OWASP ZAP 和 Nikto 偏 Web 应用与服务器配置检查，OpenVAS 是更完整的漏洞管理框架。
  • 无线侧 Aircrack-ng、Kismet；密码恢复 Hashcat 和 John the Ripper。

日常加固反而朴素：DNS 层用 AdGuard Home 或 Pi-hole 挡广告与跟踪；远程访问用 Tailscale 或 WireGuard 组虚拟网络，别把管理端口直接暴露到公网；需要内网穿透时 frp 和 sing-box 是常见选择。密码交给 KeePassXC 或 Bitwarden，自托管可以看看 Vaultwarden。

最后提醒一句：能力越强越要有边界意识。扫描、爆破、抓包这些操作，只对自己拥有或明确授权的目标使用。
