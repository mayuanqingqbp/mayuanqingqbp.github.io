常见问题

「常用精选」和「小众优选」到底差在哪？

常用精选是天天上手的高频工具，小众优选名气不大，但各自解决某个具体问题。两者不分高下，编号只为引用方便（001–221 / 222–500）。反馈问题时直接报编号，比贴截图清楚得多。

星标数、语言、许可证这些数据哪来的？

精选条目的主语言和许可证来自各项目的 GitHub 仓库，LICENSE 文件或仓库页面，参考用，可能落后于仓库现状。热榜的星标数是抓取那一刻的实时值，本站不参与维护。分类按条目内容人工标注，个别可能标错。

热榜的入选规则是什么？

靠 GitHub Search API 自动抓取，窗口分三档：天（近 1 天创建、星标 200 以上）、周（近 7 天、500 以上）、月（近 30 天、1500 以上），按星标降序排。热榜页上点「窗口 天 / 周 / 月」切换，每档自带 10 分钟缓存，按「刷新热榜」就强制重抓。线上访问时，抓取和缓存都在本站的服务端函数里完成，浏览器不直接连 GitHub，不占直连额度。只有本地打开这份 HTML 预览、函数用不了时，才退回浏览器直连——未登录限每分钟 10 次，刷太勤会失败。失败不是页面坏了，等一会儿再刷。

想推荐收录一个软件，或发现介绍写错了，找谁说？

为什么没有广告和埋点？

全站没有第三方脚本，没有分析，也没有用户追踪，统计跑在自己的服务端。「赞助商 / 推广 · 返佣」链接不多，每一处都标明是付费合作，目录排序和内容不受影响；不赞助也不会被降级或变慢。微信 / 支付宝 / 爱发电的赞助，只用来撑住更新的动力。

站上这些软件的版权归谁？

版权归原仓库作者所有，本站只整理数据、写介绍。每个软件遵循自己的开源许可证，MIT、GPL、Apache 都常见，一切以仓库为准。卡片上的许可证标注只是参考，要商用就去读仓库里 LICENSE 的原文。
