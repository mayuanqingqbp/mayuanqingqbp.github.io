设计工具：从修图到协作画布

先想清楚画什么，再挑工具：

  • 位图修图：GIMP 是 Photoshop 的开源对照物，功能全但界面老派；Krita 偏数字绘画，笔刷体验好得多。
  • 矢量：Inkscape 是 Illustrator 的对位产品；Gouache 是浏览器里的轻量矢量工具，UI / 品牌小改很顺手。
  • 快速草图：Excalidraw 的手绘风白板，产品讨论和头脑风暴用它；tldraw 是可嵌入自家产品的白板引擎。
  • 图表与原型：draw.io 画架构图；Penpot 是开源 Figma 的正面竞争者，浏览器里多人协作，还能自托管。
  • 三维：Blender 一家独大，建模、渲染、动画、剪辑一条龙。
  • 视频剪辑：Kdenlive 是非线性剪辑器，多轨、滤镜、关键帧动画都有。

照着产出物挑：

  • 照片处理、截图标注、界面稿 → GIMP
  • 插画、概念图、分镜 → Krita，笔刷引擎和洋葱皮动画是它的强项
  • Logo、图标、任何要无限放大的品牌资产 → Inkscape，产出是 SVG
  • 会议白板、流程草图、不要求好看 → Excalidraw，手绘风就是它的卖点
  • 架构图、时序图、UML → draw.io，可以导出图片，也可以当 diagram-as-code 用
  • 团队 UI 设计、实时协作、设计交付 → Penpot，开源、可自托管
  • 建模、渲染、动画、视频 → Blender，一个工具管全流程

常见误区是拿 GIMP 画插画、拿 Inkscape 修照片，工具没毛病，是场景选错了。先看产出物是位图、矢量还是白板，再选工具。
