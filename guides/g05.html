终端工具箱：把命令行变成工作台

一套可以直接抄的终端配置，分四块：

  • 查：ripgrep 搜内容（尊重 .gitignore、并行、大仓库毫秒级），fd 找文件，fzf 把任何列表变成模糊过滤（文件、历史、进程都行），zoxide 替代 cd，按使用频率智能跳目录。
  • 看：bat 是带高亮的 cat（行号、感知 git 状态），btop 和 htop 看进程，duf 看磁盘占用，dust 用树形视图找占空间的目录。
  • 管：tmux 做会话管理（ssh 断了会话不死，detach 之后随时回来），lazygit 和 lazydocker 是 TUI 版 Git / Docker（暂存、提交、rebase、容器、镜像全键盘操作）。
  • 运维：Uptime Kuma 做监控告警（多渠道通知、公开状态页），rclone 同步网盘（云存储的瑞士军刀，各家网盘都能搬），restic 和 Borg 做备份（都支持加密、去重、增量，restic 的云端后端选择更多）。

两个不常被提的 shell 升级：atuin 是可搜索、可跨机器同步的 shell 历史，再也不用方向键翻半天；Nushell 是结构化数据 shell，表格和对象直接过管道，思维方式跟 bash 完全不同，值得花一天试一下。

不必一次全装。先 ripgrep + fd + fzf + bat 四件套，能立刻感受到「命令行快了一个量级」，再按需加 tmux 和 lazygit。配置成本只有一份 dotfile：都放进 ~/.config，用 git 管起来，换机器时整个工作台可以整体搬走。
